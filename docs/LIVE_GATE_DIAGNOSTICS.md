# 2026-10-04 Gate 诊断与 20 步真实实验

本轮已完成四组真实 WebShop 实验：Baseline 6/31、Query 4/31、Product 15/31、Full 16/31 满分成功。每个任务最多 20 个环境动作，未运行 50 步实验。Full 本轮领先 Product 一个任务，单次小样本不足以确定稳定优势。

## 固定条件与验证

- 运行提交：`3e9d3b9502e446b548f746b5a602309f3c2bfaa7`，四组启动时工作区干净，组件源码快照及 hash 一致。该提交在 `7038550` 的行为实现上增加实际返回模型身份的统计。
- 数据：`evaluation/webshop_test_100.json` 中 31 个有 instruction 的任务；1000 个商品及 1k Lucene 索引。数据集 hash：`e83636f88d819468ea21a4ca3c0df6059f778d88590d29b78ea8884065535728`。
- 四组共享策略、模型参数、任务顺序和预算；每组 1 次重复，seed=42，temperature=0。各组独立正常抽取 schema，没有冻结抽取结果。
- 请求模型为 `deepseek-chat`；服务返回的实际模型字段为 `deepseek-flash`。正式重放 1200 次和完整任务 2937 次调用均记录该身份。旧主实验未记录返回模型身份，不能将新旧成绩变化全部归因于代码。
- Query 模式 `coverage`，最终审计 `grounded`；H1 `variant_review`、候选去重均关闭。未运行 H2 的 layered/direction 消融。
- 核对了全部 124 条任务记录的任务身份、源码、参数、动作计数和调用分项；环境步数全部不超过 20。Product/Full 共 37 次购买，执行前全部有当前商品的 READY 检查。
- API 调用错误为 0，正式审计重放响应格式错误为 0。约束抽取验证失败属于系统失败，不属于网络/API 错误。
- 原始行为代码的 69 项离线回归和 17 项上游回归此前已通过；本轮完成后仅补充分析文档，没有修改运行策略或评分。

成功定义仍为任务终止且 reward > 0.999999。部分得分购买另计；所有平均值包含完整的 31 个任务，包括抽取失败任务。

| 配置 | 满分成功 | 成功率 | 部分得分购买 | 平均 reward | 平均环境步数 | 平均 API 调用 | API 调用总数 |
|---|---:|---:|---:|---:|---:|---:|---:|
| Baseline：两 Gate 均关 | 6/31 | 19.35% | 2 | 0.2204 | 16.97 | 20.45 | 634 |
| Query：仅 Query Gate | 4/31 | 12.90% | 4 | 0.1683 | 16.32 | 23.32 | 723 |

Product 与 Full 共同满分成功 14 个任务；只有 Product 成功的是 `B089VWZB64`，只有 Full 成功的是 `B07CXTNVRJ`、`B08J3WFRBT`。所以“Full 多一个成功”实际上包含两个新增成功和一个丢失成功。不能从总数推出 Query Gate 对每个任务都有帮助。

Query 单独开启本轮仍低于 Baseline；与 Product 组合后总数略高。独立抽取和策略输出存在波动，这一轮不能确认交互机制或因果增益。

三个 Gate 组都在 `B07K6TCDR9`、`B09BW4S48B` 抽取验证失败，各计 2 个失败，分母保持 31。Baseline 正常执行，不因 Gate 的抽取问题而人工判失败。停止原因为 step_budget 的数量分别是 23、21、11、10。

在有效 schema 的 29 任务子集，Query/Product/Full 满分成功分别为 4/29、15/29、16/29；此为排除了两个失败任务的条件结果，不能代替上述完整系统指标。

历史 `b8d48c5` 快照的对应成功数是 6、5、12、9，保留在 [原测试记录](LIVE_VALIDATION.md)。新一轮为 6、4、15、16。两轮间有代码、审计上下文和可能的后端模型差异，且每轮都仅重复一次，禁止把差值解释为某一项修改的独立效果。

## 部分得分购买：READY 仍可能出错

Product 与 Full 的三个部分得分任务相同，不能计为满分成功，也不能仅凭环境分数将所有问题都认定为语义误放行。

| 任务 | 购买商品 | reward | 已核实的情况 |
|---|---|---:|---|
| B08WG7VLQF | B08WG7VLQF | 0.75 | 页面有 scent=`fragrance free` / `north bondi scented`，购买时选中值为空。抽取将 fragrance free 仅作为属性，post_selection 为空；文字匹配与审计放行，遗漏了真实选择器要求。环境从指令显式短语识别出 scent=`fragrance free`，该选项未得分。 |
| B09MW563KN | B08LD3XCPQ | 0.3333 | 可见 Features 写有 improve oral health、make our breath fresher，Gate 将其视为 oral hygiene / fresh breath 的语义支持；原生评分的属性字符串匹配两项均未命中。这是评分口径与语义判定的差异案例，须人工复核，不能直接断言 Gate 错误。 |
| B09MCF64RM | B09JJ5W1N4 | 0.6667 | schema 把 for eye shadow 并入商品类别，只独立检查 high quality。审计将通用 makeup/cosmetic bag 认定为 eye shadow bags/cases，原生属性评分未命中 eye shadow。需复核用途是否在类别泛化中被弱化。 |

这三个状态的可见证据另存于运行目录的 `partial-evidence-*.txt`。本轮没有修改评分或覆盖结果。第一例的选择器绑定遗漏是明确工程问题；另两例需区分可见语义支持、用户用途要求和原生字符串评分。

## 审计重放

先对 3 个预选状态做 4 臂 × 5 次 smoke 重放，60 次真实调用，无 API/格式错误；随后正式运行 15 个冻结状态 × 4 臂 × 20 次，共 1200 次真实调用，全部绕过审计缓存。各臂区块顺序打乱。

15 个状态来自历史争议任务 `B07QXZL1K5`、`B07CXTNVRJ`、`B096MM7XM4`、`B094JTNPWK`、`B07N864Q64` 的不同证据阶段。它们是诊断样本，不能代表全体任务分布。历史变体上下文从轨迹重建，明确标记 reconstructed。

| 审计臂 | 来源 | ACCEPT | INSPECT | REJECT | 调用/格式错误 |
|---|---|---:|---:|---:|---:|
| legacy | 762944e 聚焦职责 | 241 | 39 | 20 | 0 |
| benchmark | b8d48c5 无变体上下文 | 48 | 228 | 24 | 0 |
| variant | 464cfe5 变体上下文 | 300 | 0 | 0 | 0 |
| grounded | 当前结构化审计 | 300 | 0 | 0 | 0 |

每个臂的 300 次调用是 15 个状态各重复 20 次，不能当成 300 个独立任务。状态级分布与 Wilson 区间在 `formal-replay/summary.json` 中；即使某状态 20/20 接受，其条件 Wilson 95% 区间约为 [0.839, 1]，也不意味着总体正确率为 100%。

variant 与 grounded 在这些状态中的输出标签完全一致，因此本轮没有证据证明新增审计职责措辞优于既有变体上下文版本。benchmark 与其他臂的差异同时包含提示词和上下文变化，不是单一措辞实验。稳定接受也可能是稳定误判；状态级人工标签仍为空，正确率、误接受和误拒绝指标保留 null。

## matcher 合成诊断

9 个已知查询例子中 8 个符合预期，使用 6 次 API 调用，其余为规则/精确匹配，无 API 错误。该小集是诊断工具，不是总体准确率估计。

失败例：要求品牌 Acme，查询写 Beta；matcher 返回 MISSING，而非预期的 CONTRADICTED。coverage 修复因此追加 Acme，留下 `Beta ... Acme`，没有删除冲突品牌。说明“缺失追加 / 矛盾重建”的修复质量仍依赖 matcher 区分缺失与替换。本轮未在实验途中修复，以免混用不同源码结果。

## 后续修复 2026-10-05

本节记录后续代码修复，上述历史结果保持原样。Product Gate 将明确匹配真实选择器的普通属性纳入现有选项检查和动作建议；多个匹配组保持未解决，已确认冲突仍阻断购买，共享 schema 不改写。Query Gate 在明确品牌未得到支持时重建查询，普通属性遗漏继续追加；这是修复策略的兜底，不代表 matcher 已能可靠识别所有品牌替换。

81 项离线回归通过，其中新增 12 项覆盖选项绑定、选择建议、错误/过期选择、无选择器、组歧义、价格冲突及品牌修复。另在本地真实 WebShop 沿用 B08WG7VLQF 原轨迹到购买前：Gate 返回 INSPECT 并建议 click[fragrance free]；执行选择后，该商品购买 reward 为 1.0，历史未选择时为 0.75。此检查冻结原类别判断、使用脚本化 ACCEPT 审计，只验证绑定执行和环境评分，付费 API 调用为 0；不能视为完整模型复测。检查脚本与记录位于本机 results/simple-gate-fix-check/。

修复未新增模块、运行阶段或配置开关，仍使用正式四组入口与默认 20 步。修复规则本身不增加模型调用，但多选一次选项会占用环境动作，品牌重建也可能损失有用搜索词；整体成功率和总成本尚未重测。未重新运行 H1/H2、审计重放或四组付费实验。
